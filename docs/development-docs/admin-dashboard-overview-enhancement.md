# 管理后台「运营概览」增强需求说明

本文档汇总管理平台概览页建议**新增与优化**的功能点，基于当前实现梳理（接口 `GET /api/admin/dashboard/summary`、页面 `AdminDashboard.vue`），用于排期与验收。

---

## 一、现状摘要（便于对照）

| 能力 | 当前状态 |
|------|----------|
| 接口返回字段 | `total_users`、`enabled_channels`、`today_requests`、`today_tokens`、`today_cost_quota` |
| 前端展示 | 仅 4 张卡片（缺 `today_cost_quota`） |
| 今日统计实现 | 拉取当日全部 `UsageLog` 后内存聚合，数据量大时存在性能风险 |

---

## 二、功能清单（全部项）

### 2.1 立刻值得做（低成本、对齐现有数据）

1. **展示「今日消耗」**  
   接口已返回 `today_cost_quota`，前端补充展示（独立卡片或并入说明区），并明确单位（与站点额度/人民币换算规则一致）。

2. **错误与加载态**  
   请求失败、超时、`code !== 0` 时给出明确提示与重试；加载中使用骨架屏或占位，避免空白。

3. **数据刷新**  
   提供手动刷新按钮；可选支持定时自动刷新（间隔可配置或固定如 60s）。

4. **浅色 / 多主题一致性**  
   概览卡片与布局在 `dawn`/`paper` 等浅色主题下避免过深底（如硬编码 `bg-slate-900`），与控制台侧 `th-glass`、`--th-*` 等模式对齐。

### 2.2 后端统计方式优化（规模上来后必做）

5. **今日统计改为数据库聚合**  
   避免对今日 `UsageLog` 全量 `All` 再循环；改为 `COUNT` / `SUM` 等聚合查询，必要时为 `request_time`（及相关筛选字段）补充索引。

6. **扩展 `summary` 或新增 `dashboard/detail` 类接口**  
   在可控性能下增加：昨日或近 7 日请求数、Token、消耗；支持简单环比（相对昨日变化百分比等）。

### 2.3 运营看板常见维度扩展（需新聚合或新接口）

7. **时间维度可视化**  
   近 7/30 日请求、Token、消耗的迷你趋势（折线或小柱状图）。

8. **模型维度**  
   今日或近 7 日 Top 模型（按请求数或 Token），与「模型市场」管理页形成呼应。

9. **渠道维度**  
   启用/禁用渠道数量、各渠道请求占比或异常渠道提示，与「渠道管理」呼应。

10. **用户与分组**  
    如：日活（当日有日志的去重用户数）、新注册用户趋势（依赖 `User` 创建时间等字段）、分组数量；可选「余额/额度异常」规则与简要告警（需产品定义阈值）。

11. **日志与风险**  
    若底层数据支持：今日或近 7 日 4xx/5xx、失败率等（依赖 `UsageLog` 或网关日志字段）。

### 2.4 导航与可执行概览（提升效率）

12. **快捷入口**  
    概览内提供直达：用户管理、渠道、分组、用量日志、模型市场、公告等（与侧栏模块一致）。

13. **关键列表摘要**  
    如：最近 N 条用量摘要、最近变更的渠道、待发布公告列表等；可依赖现有列表 API 的 `limit` 或新增轻量只读接口。

### 2.5 系统与合规（可选，视产品定位）

14. **管理审计摘要**  
    最近若干条 `AdminAuditLog`（操作者、时间、动作摘要），需只读列表接口与权限说明。

15. **系统健康**  
    数据库/网关连通性、应用版本、只读配置摘要等（与控制台「服务可用性」类似，面向运维视角）。

16. **配额与告警占位**  
    磁盘、队列、上游账户余额等——按实际部署再接入；可先 UI 占位或「未接入」说明。
