# TraceHub · 企业采购与定制方案

**迹径 TraceHub — 循迹未来**

> 面向：计划 **采购/部署 AI API 网关**、开展 **模型聚合运营**、或建设 **企业内网统一 AI 出口** 的企事业单位。

---

## 一句话

**TraceHub 是一套可私有化部署、可二次开发、可品牌定制的开源 AI API 网关全栈产品**——将多模型能力收敛为 **OpenAI 兼容 `/v1` 接口**，并自带 **用户体系、计费运营、管理后台与营销官网**，帮助企业 **缩短 3～6 个月自研周期**，快速具备 **可运营、可审计、可扩展** 的 AI 服务能力。

---

## 为什么选择 TraceHub，而不是从零自研？

| 企业常见困境 | TraceHub 带来的答案 |
|-------------|-------------------|
| 自研网关周期长、人力贵 | **成熟代码库 + 文档 + Docker 一键栈**，数周内可完成 POC 到内网试点 |
| 多模型协议不一、维护成本高 | **统一 OpenAI 兼容出口**，流式、工具调用、多模态在网关侧对齐 |
| 要做商业化运营缺「骨架」 | **用户 / Key / 分组倍率 / 兑换码 / 用量日志** 等运营能力已内置 |
| 密钥与合规压力大 | **渠道凭据 AES 加密**、用户 Key **哈希存储**、**审计日志**、可私有化 **数据不出域** |
| 需要自主品牌与交付 | **站点品牌化、Logo、多语言前台**；支持 **源码交付 + 定制开发** |

**结论**：把预算用在 **差异化业务与合规**，而不是重复造「路由 + 计费 + 控制台」轮子。

## 您采购/合作后得到什么？

### 1. 可运行的产品（非 PPT）

- **网关核心**：对话、模型列表、Embeddings、图像、音频、视频、Realtime 等（按部署配置开启）
- **智能路由**：分组 + 模型选路、优先级/权重、故障转移、可选 Redis 粘性会话
- **计费引擎**：Token 计量、按次/混合计费、分组与用户倍率、免计费模型策略
- **用户端**：注册登录、API Key、余额用量、兑换码、多语言控制台
- **管理端**：用户/渠道/分组/定价、调用日志、兑换码批量、审计、站点配置
- **营销官网**：Hero、模型展示、价格 FAQ（可替换为自有品牌）
- **运维接口**：`/health`、`/ready`、`/metrics`（Prometheus）

### 2. 可交付的工程资产

- **完整源码**（MIT 许可证，便于企业内二次开发）
- **数据库模型与迁移**（Ent ORM + PostgreSQL）
- **部署描述**（Docker Compose、单二进制托管 SPA）
- **产品与开发文档**（架构、API、数据库、运维说明）

### 3. 可选商务服务（循迹未来）

- **私有化部署实施**（内网 / 专有云 / 混合云）
- **品牌与界面定制**（Logo、域名、文案、主题）
- **功能定制开发**（支付、企业 SSO、RBAC、合规字段、专属路由策略等）
- **培训与维保**（上线陪跑、版本升级、故障响应）

## 六大产品优势（面向企业决策者）

### 优势一：统一接入，立刻具备「多模型聚合」能力

下游（业务系统、Agent、内部应用）只对接 **一套 OpenAI 风格 API**；后台多条上游线路、协议差异与流式格式由 TraceHub 消化。适合 **统一技术栈、降低集成与供应商锁定成本**。

### 优势二：可运营的商业化骨架

不仅是转发代理，而是 **可对外或对内运营的平台**：用户体系、API Key、余额与用量、兑换码营销、分组差异化定价。支撑 **拉新—试用—转化—留存** 的基础闭环，适合 AI 中转、行业云、集团能力开放平台。

### 优势三：调度与计费「能讲清楚」

- 路由：健康准入、Failover、多通道池化、稳健度偏好、粘性会话  
- 计费：Token / 按次 / 混合模式；全局与分组级策略；调用日志可对账  
便于 **财务、运维、研发** 在同一套规则下协作，减少「账单说不清」的组织摩擦。

### 优势四：安全与内控友好

- 上游渠道密钥 **AES-GCM 加密存储**  
- 用户 API Key **哈希保存**  
- 管理端 **审计日志**  
- 可拦截易误用的云端控制台类路径  
- 支持 **私有化部署**，满足 **数据不出域、密钥自持** 等要求  

### 优势五：生产级运维与扩展

- Go 高并发网关 + 无状态水平扩展  
- Prometheus 指标与健康探针  
- YAML 集中配置，适配多环境发布  
适合纳入企业现有 **监控、发布、容灾** 体系。

### 优势六：开源可信 + 定制空间

- **MIT 许可证**：可审计、可 fork、可内网长期演进  
- **模块化代码结构**（网关 / 计费 / 管理 / 前端分离）  
- 路线图可扩展：在线支付、OAuth、细粒度 RBAC、Webhook、语义缓存等（可按项目单独立项）

## 可定制方向（示例）

以下均可作为 **POC 后立项** 的定制项，按优先级与工时评估：

- **品牌与前台**：Logo、主题色、域名、官网文案、多语言扩展  
- **支付与账务**：支付宝 / 微信 / Stripe、发票字段、对账导出  
- **企业身份**：LDAP / OIDC / 企业微信 / 钉钉 SSO；细粒度 RBAC  
- **安全合规**：IP 白名单、日志脱敏策略、数据保留周期、等保对标配置  
- **路由与 SLA**：专属 Failover 策略、渠道探测、成本/延迟优先路由  
- **协议与模型**：新增上游类型、Realtime 增强、行业专属模型映射  
- **集成**：Webhook 事件、对接现有计费/CRM/工单系统  

**建议**：首次沟通携带「目标用户规模、部署环境、必接模型、合规要求、上线时间」五项信息，便于 **1～2 个工作日内** 给出粗估方案。

## 技术架构（采购评审摘要）

| 维度 | 说明 |
|------|------|
| 后端 | Go 1.25+、Gin、Ent ORM、PostgreSQL |

| 前端 | Vue 3、Vite、Tailwind CSS v4 |
| 部署 | Docker Compose；单进程可托管 SPA |
| 许可 | MIT（源码可读、可改、可私有化） |
