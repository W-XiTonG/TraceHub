## 五、完整口播文稿（约 90 秒）

> 字数约 400 字；语速中等约 85–95 秒。括号内为语气提示。

**【0:00–0:08 开场】**

还在为多款大模型，分别对接不同的接口和账号吗？

**TraceHub**，是循迹未来推出的 **AI API 统一网关**——  
下游只用 **一套 OpenAI 兼容接口**，即可调用平台已开放的多种主流大模型。

**【0:08–0:20 痛点】**

每多接一个模型，就多一套 SDK、多一把密钥、多一条运维链路。  
团队成本高，出问题还难对账。

TraceHub 把这件事，收敛成 **一次接入、统一治理**。

**【0:20–0:45 演示】**

接入很简单：  
**注册账号** → 在控制台 **创建 API Key** → 把客户端的 **Base URL** 指向 TraceHub。

你熟悉的 `chat.completions`、流式 SSE，**不用改业务语义**，换地址、换 Key 就能跑。

新用户注册还有 **试用额度**（额度规则以站内公示为准），零成本先把链路调通。

**【0:45–1:05 亮点】**

不只是转发。  
**智能路由**：多线路按权重分流，异常时可自动切换备用渠道；  
**透明计费**：按 Token 计量，用量与日志可查，成本可预期；  
**安全可控**：密钥加密存储，管理端可审计；  
**可观测**：健康检查与 Prometheus 指标，方便接入现有监控。

官网、用户控制台、管理后台 **三端一体**，支持简中、繁中、英文界面。

**【1:05–1:20 私有化 + 企业】**

TraceHub **开源可私有化**：Docker Compose 一键拉起，适合自建中转站或 **企业内网网关**。

循迹未来提供 **企业定制开发**：品牌白标、SSO 对接、合规字段、支付与运营策略、专属 SLA——  
按合规与交付边界，从 POC 到上线。

**【1:20–1:30 收尾 CTA】**

个人和团队，现在就可以打开 **{API_BASE}** 注册试用：  
创建 API Key，改一下 Base URL，就能调通主流大模型。

官网域名 **{FUTURE_SITE_HOST}** 正在备案，通过后将在站内公告，并切换到 **HTTPS** 正式访问。

要做 **私有化部署** 或 **企业定制** 的朋友，欢迎拨打 **{BUSINESS_PHONE}**，**微信同号**，添加时请备注「TraceHub」。

**迹径 TraceHub**——多模型，一条链路。  
**循迹未来**，让 AI 接入更简单。
